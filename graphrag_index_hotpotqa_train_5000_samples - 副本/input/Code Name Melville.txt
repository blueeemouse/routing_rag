Code Name Melville

Code Name Melville (original French title: Sous le nom de Melville) is a feature length documentary about Jean-Pierre Melville, directed by Olivier Bohler and produced by Raphaël Millet for Nocturnes Productions in 2008.

 Its world premiere took place in November 2008 at the Golden Horse Film Festival in Taipei (Taiwan).

 It has been shown on French channel CinéCinéma Classic in March–April 2010, and on Belgian channel La Deux (RTBF) in May 2010.

 It is the first feature documentary about Jean-Pierre Melville since he died in 1973.
