Guilty Gear X2 updated versions

"Guilty Gear X2" (released as "Guilty Gear XX: The Midnight Carnival" in Japan) is a 2D fighting video game developed by Arc System Works, and published by Sammy Studios.

 First released on May 23, 2002, for the arcades, in Japan, it was later ported to the PlayStation 2, and published in North America in 2003.

 The game received updated versions for several platforms: "Guilty Gear X2 #Reload" (2003), "Guilty Gear XX Slash" (2005), "Guilty Gear XX Accent Core" (2006), "Guilty Gear XX Accent Core Plus" (2008), and "Guilty Gear XX Accent Core Plus R" (2012).

 Each update served to the company to perform adjustments comparing to the previous versions and was published in different platforms and regions.
