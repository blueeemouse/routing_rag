Power Pivot

Power Pivot is a feature of Microsoft Excel.

 It is available as an add-in in Excel 2010 and 2013, and is included natively in Excel 2016.

 PowerPivot extends a local instance of Microsoft Analysis Services Tabular that is embedded directly into an Excel Workbook.

 This allows a user to build a ROLAP model in PowerPivot, and use pivot tables to explore the model once it is built.

 This allows Excel to act as a Self-Service BI platform, implementing professional expression languages to query the model and calculate advanced measures.
