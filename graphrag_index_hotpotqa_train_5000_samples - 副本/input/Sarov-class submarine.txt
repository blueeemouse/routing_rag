Sarov-class submarine

The Sarov class is a submarine class built by Russia.

 There is a single boat of the class, the "Sarov" itself.

 It serves to test and develop new technologies and new weaponry for the Russian Navy.

 It was first revealed publicly when details of the boat were published by accident on the Sarov, Nizhny Novgorod region's local government website as part of an account of a meeting with its commander.

 The number of the submarine project was given as 20120 and some technical and tactical characteristics were revealed as well.
