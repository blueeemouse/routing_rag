Lego Superman

Lego Superman is a part of the 2012 Lego theme DC Universe Superheroes which features character Superman.

 The first set was released in December 2012; the second in 2013 based on the Superman film "Man of Steel".

 The characters from the first set featured in "" which were Superman, Wonder Woman and Lex Luthor.

 As of October 2012 there are four Lego Superman sets.
