Wayne State College

Wayne State College is a four-year public college in the Nebraska State College System in Wayne, Nebraska, United States.

 The current enrollment is 3,571.

 The college opened as a State Normal School in 1910 after the State purchased the private Nebraska Normal College (established 1891).

 The State Normal College became State Normal School and Teacher's College in 1921.

 This was changed to Nebraska State Teachers College at Wayne in 1949 and the present name was adopted in 1963.
