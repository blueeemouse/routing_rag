Grace (plotting tool)

Grace is a free WYSIWYG 2D graph plotting tool, for Unix-like operating systems.

 The package name stands for "GRaphing, Advanced Computation and Exploration of data."

 Grace uses the X Window System and Motif for its GUI.

 It has been ported to VMS, OS/2, and Windows 9*/NT/2000/XP (on Cygwin).

 In 1996, Linux Journal described Xmgr (an early name for Grace) as one of the two most prominent graphing packages for Linux.
