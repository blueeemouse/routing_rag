QuakeWorld

QuakeWorld (abbreviated QW) is an update to id Software's seminal multiplayer deathmatch game, "Quake", that enhances the game's multiplayer features (namely UDP support) to allow people with dial-up modems to achieve greatly improved responsiveness when playing on Internet game servers.

 Modern broadband connections such as cable and DSL can use the QW network handling and game physics as well.

 Official id Software development stopped with the test release of QuakeWorld 2.33 on December 21, 1998.

 The last official stable release was 2.30.

 QuakeWorld has been described by IGN as the first popular online first-person shooter.
